## 一、互不相交三元组的打包

### (a) 冲突图

冲突图是一条路径，边上标注两个三元组的共同元素。

```text
     c       e       g       i
S1 ----- S2 ----- S3 ----- S4 ----- S5
```

一个打包可行，当且仅当所选顶点构成独立集，即任意两个选中顶点之间都没有边。

### (b) 所有极大打包

共有四个极大打包，收益如下。

| 打包 | 收益 |
| --- | --- |
| $\{S_1,S_3,S_5\}$ | $4+5+4=13$ |
| $\{S_1,S_4\}$ | $4+7=11$ |
| $\{S_2,S_4\}$ | $8+7=15$ |
| $\{S_2,S_5\}$ | $8+4=12$ |

按是否选择 $S_3$ 分类，可以证明没有遗漏。

若选择 $S_3$，则不能选择 $S_2,S_4$。为了达到极大，必须再加入 $S_1,S_5$，得到 $\{S_1,S_3,S_5\}$。

若不选择 $S_3$，则必须从 $S_1,S_2$ 中恰选一个，并从 $S_4,S_5$ 中恰选一个。其中，$\{S_1,S_5\}$ 仍可加入 $S_3$，所以不是极大打包。其余三个组合正是表中剩下的三个打包。对表中每个打包，所有未选三元组都与某个已选三元组冲突，因此均为极大打包。

### (c) Alice 和 Bob 的选择

Alice 应选择 $\{S_1,S_3,S_5\}$，共 3 个三元组。Bob 应选择 $\{S_2,S_4\}$，收益为 15。

任何非极大打包都可以再加入一个三元组，使数量增加。由于所有收益均为正，收益也会增加。因此，数量最多和收益最高的打包都必须是极大打包，比较第 (b) 问的表格即可。

### (d) 改变 S3 的收益

由于 $x\gt0$，包含 $S_3$ 的最佳打包为 $\{S_1,S_3,S_5\}$，收益为 $x+8$。不包含 $S_3$ 的最佳打包为 $\{S_2,S_4\}$，收益为 15。

所以，每个收益最大的打包都包含 $S_3$，当且仅当

```math
x+8\gt15
\quad\Longleftrightarrow\quad
x\gt7.
```

由于 $x$ 为正整数，答案为 $x\ge8$。

当 $x=7$ 时，恰有两个最优打包：$\{S_1,S_3,S_5\}$ 与 $\{S_2,S_4\}$，收益都为 15。因此，只有部分最优打包包含 $S_3$。当 $1\le x\le6$ 时，唯一最优打包为 $\{S_2,S_4\}$。

## 二、轮流选择的公平分配

### (a) 选择顺序与最终分配

各轮选择如下，最后一轮只有两次选择。

| 轮次 | Alice | Bob | Carol |
| --- | --- | --- | --- |
| 1 | $g$ | $d$ | $b$ |
| 2 | $e$ | $c$ | $h$ |
| 3 | $a$ | $f$ | 物品已分完 |

最终分配为

```math
X_A=\{g,e,a\},\qquad
X_B=\{d,c,f\},\qquad
X_C=\{b,h\}.
```

### (b) 估值表与嫉妒关系

每一行都使用该行参与者的估值计算三个物品集合的价值。

| 参与者 | $X_A$ | $X_B$ | $X_C$ |
| --- | --- | --- | --- |
| Alice | $8+7+6=21$ | $1+5+4=10$ | $2+3=5$ |
| Bob | $8+6+2=16$ | $7+5+3=15$ | $1+4=5$ |
| Carol | $6+3+2=11$ | $8+5+1=14$ | $7+4=11$ |

只有两对嫉妒关系：$(B,A)$ 和 $(C,B)$，因为 $16\gt15$ 且 $14\gt11$。Carol 对自己与 Alice 的物品集合估值相同，因此 $(C,A)$ 不构成嫉妒关系。

### (c) EF1

该分配满足 EF1。对于 Bob 对 Alice 的嫉妒，从 Alice 的物品集合中移除 $g$，有

```math
v_B(X_A\setminus\{g\})=6+2=8
\le15=v_B(X_B).
```

对于 Carol 对 Bob 的嫉妒，从 Bob 的物品集合中移除 $d$，有

```math
v_C(X_B\setminus\{d\})=5+1=6
\le11=v_C(X_C).
```

这两对是全部嫉妒关系，且都能通过从被嫉妒的物品集合中移除一件物品来消除嫉妒。

## 三、博弈论

### 第一部分 选择工作坊场地

### (a) 最佳回应与纯策略纳什均衡

根据收益比较，各社团的最佳回应如下。

| 社团 | 对方的选择 | 最佳回应 | 收益比较 |
| --- | --- | --- | --- |
| 艺术社 | $N$ | $S$ | $3\gt1$ |
| 艺术社 | $S$ | $N$ | $5\gt2$ |
| 读书社 | $N$ | $S$ | $3\gt2$ |
| 读书社 | $S$ | $N$ | $5\gt1$ |

将艺术社的选择写在前面，纯策略纳什均衡为

```math
(N,S),\qquad(S,N).
```

在这两个结果中，双方都采用了最佳回应。在 $(N,N)$ 中，艺术社改选 $S$ 可以提高收益；在 $(S,S)$ 中，艺术社改选 $N$ 可以提高收益。因此，没有其他纯策略纳什均衡。

### (b) 帕累托效率

两个均衡在四种结果中都具有帕累托效率。

在 $(N,S)$ 中，收益为 $(5,3)$。其余每种结果都会使艺术社的收益低于 5，因此都无法构成帕累托改进。

在 $(S,N)$ 中，收益为 $(3,5)$。其余每种结果都会使读书社的收益低于 5，因此都无法构成帕累托改进。

### 第二部分 分配志愿者资助金

### (c) 联盟价值

任意两个社团都能提供至少五名志愿者，而任意单个社团都不能。因此，所有联盟的价值为

```math
\begin{aligned}
v(\varnothing)&=v(\{A\})=v(\{B\})=v(\{C\})=0,\\
v(\{A,B\})&=v(\{A,C\})=v(\{B,C\})=v(\{A,B,C\})=90.
\end{aligned}
```

### (d) 夏普利值

在每种顺序中，第二个到达的社团使联盟首次获得资助。因此，该社团的边际贡献为 90，其余两个社团的边际贡献均为 0。

| 到达顺序 | 首次使联盟获得资助的社团 | $\Delta_A$ | $\Delta_B$ | $\Delta_C$ |
| --- | --- | --- | --- | --- |
| $ABC$ | $B$ | 0 | 90 | 0 |
| $ACB$ | $C$ | 0 | 0 | 90 |
| $BAC$ | $A$ | 90 | 0 | 0 |
| $BCA$ | $C$ | 0 | 0 | 90 |
| $CAB$ | $A$ | 90 | 0 | 0 |
| $CBA$ | $B$ | 0 | 90 | 0 |

每个社团都在六种顺序中的两种贡献 90，因此

```math
\phi_A=\phi_B=\phi_C
=\frac{2\cdot90}{6}=30.
```

### (e) 核心

夏普利分配 $(30,30,30)$ 不属于核心。联盟 $\{A,B\}$ 可以获得 90，并按 $(45,45)$ 分配。两名成员都比原来的 30 获得更多，因此该联盟能够阻挡这一分配。

事实上，核心为空。假设存在核心分配 $(x_A,x_B,x_C)$，则必须满足

```math
x_A+x_B+x_C=90,\qquad x_A,x_B,x_C\ge0.
```

任意两个社团组成的联盟都能获得 90。为了阻止它们退出，必须有

```math
x_A+x_B\ge90,\qquad
x_A+x_C\ge90,\qquad
x_B+x_C\ge90.
```

若某一对社团合计获得少于 90，它们就可以将差额平分，使双方都严格获益。将以上三个不等式相加，得到

```math
180=2(x_A+x_B+x_C)\ge270,
```

矛盾。因此，不存在任何一种对这 90 美元的分配属于核心。
