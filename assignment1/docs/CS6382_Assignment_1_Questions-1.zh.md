## 问题 1：有两种资源约束的背包问题

有 $n \ge 1$ 个物品。物品 $i$ 的价值为 $v_i \gt 0$，消耗两种资源的数量分别为 $a_i, b_i \ge 0$。两种资源的预算分别为 $A, B \gt 0$。假设每个物品都满足 $a_i \le A$ 和 $b_i \le B$，因此每个单物品集合都是可行的。所有价值、资源需求量和预算均为有理数，且均已显式给出。

找出一个子集 $S$，使下式最大：

```math
v(S) = \sum_{i \in S} v_i
```

约束条件为

```math
\sum_{i \in S} a_i \le A, \qquad \sum_{i \in S} b_i \le B.
```

**(a)** 用 $x_i$ 表示是否选择物品 $i$，写出整数规划模型及其线性规划松弛。解释为什么

```math
\mathrm{OPT} \le \mathrm{OPT}_{LP}.
```

**(b)** 考虑 $A = B = 1$，以及两个价值均为 $1$ 的物品，其资源需求量为

```math
(a_1, b_1) = (1, \delta), \qquad (a_2, b_2) = (\delta, 1), \qquad 0 \lt \delta \lt 1.
```

求最优整数解和唯一的最优线性规划解。如果把每个分数变量都向下取整为零，会发生什么？

**(c)** 证明：线性规划可行域的每个极点至多有两个分数变量。

*提示：* 如果至少有三个变量为分数，找出一个以这些变量为支撑集的非零扰动 $d$，使其满足

```math
\sum_i a_i d_i = 0, \qquad \sum_i b_i d_i = 0.
```

**(d)** 设 $x^*$ 是一个最优极点，并定义

```math
S = \{i : x_i^* = 1\}.
```

设 $j$ 是价值最大的物品。考虑返回 $S$ 与 $\{j\}$ 中价值较高者的算法。证明其可行性，并证明这是一个多项式时间的 3-近似算法。

## 问题 3：带权支配集

设 $G = (V, E)$ 是一个最大度数为 $\Delta$ 的简单无向图。每个顶点 $v$ 的费用为正有理数 $c_v$。定义其闭邻域为

```math
N[v] = \{v\} \cup \{u : uv \in E\}.
```

如果每个顶点都属于某个 $v \in D$ 的 $N[v]$，则集合 $D \subseteq V$ 称为支配集。目标是最小化 $c(D)$。

考虑以下算法。初始时 $U = V$ 且 $D = \varnothing$。当 $U \ne \varnothing$ 时，在分母为正的顶点中选择一个使下式最小的顶点 $v$：

```math
\frac{c_v}{|N[v] \cap U|}
```

将 $v$ 加入 $D$，并从 $U$ 中移除 $N[v]$。

**(a)** 一种更简单的启发式算法忽略费用，每次选择当前能支配最多未被支配顶点的顶点。构造一个只有三个顶点的实例，使该启发式算法的近似比可以任意大。

**(b)** 每当上述算法选择顶点 $v$ 时，对该步新被支配的每个顶点 $u$ 赋予价格

```math
p_u = \frac{c_v}{|N[v] \cap U|}
```

其中 $U$ 取选择 $v$ 之前的状态。证明

```math
c(D) = \sum_{u \in V} p_u.
```

**(c)** 固定一个顶点 $v$，按照 $N[v] = \{u_1, \ldots, u_s\}$ 中各顶点被支配的顺序列出它们；同时被支配的顶点可任意打破平局。证明

```math
p_{u_j} \le \frac{c_v}{s-j+1}.
```

进而证明

```math
\sum_{u \in N[v]} p_u \le H_s c_v, \qquad H_s = \sum_{j=1}^{s} \frac{1}{j}.
```

**(d)** 利用一个最优支配集证明，该算法是一个 $H_{\Delta+1}$-近似算法。

解释为什么它会在多项式时间内终止。

## 问题 4：通过终端最小生成树构造 Steiner 树

设 $G = (V, E)$ 是一个边费用均为正有理数的连通无向图。指定集合 $R \subseteq V$ 包含 $k \ge 2$ 个终端。

Steiner 树是 $G$ 中一棵包含所有终端的树；它也可以包含其他顶点。目标是最小化其总边费用。

对终端 $u, v$，令 $d(u, v)$ 表示它们在 $G$ 中的最短路径距离。考虑以下算法：

1. 在 $R$ 上构造完全图，令边 $uv$ 的费用为 $d(u, v)$。
2. 计算该完全图的一棵最小生成树 $M$。
3. 将 $M$ 的每条边替换成 $G$ 中相应的一条最短路径。
4. 返回这些路径并集的一棵生成树 $A$。

**(a)** 证明 $d$ 满足三角不等式，且该算法可以在多项式时间内实现。

**(b)** 证明 $A$ 是可行的 Steiner 树，且

```math
c(A) \le d(M).
```

**(c)** 设 $T^*$ 是一棵最优 Steiner 树。当 $k \ge 3$ 时，证明这些终端存在一个循环排列 $r_1, \ldots, r_k$，满足

```math
\sum_{i=1}^{k} d(r_i, r_{i+1}) \le 2c(T^*), \qquad r_{k+1} = r_1.
```

*提示：* 将 $T^*$ 的每条边复制一份，并考虑一条 Euler 回路。

**(d)** 从 (c) 中的终端环上删除一条费用最高的边。利用所得路径证明

```math
c(A) \le 2\left(1 - \frac{1}{k}\right)c(T^*).
```

另行证明当 $k = 2$ 时，该算法求得精确最优解。

**(e)** 用以下实例族说明该保证是紧的。存在 $k \ge 3$ 个终端和一个额外顶点 $s$。从 $s$ 到任一终端的每条边费用为 $1$，任意两个终端之间的每条边费用为 $2 - \varepsilon$，其中

```math
0 \lt \varepsilon \lt \frac{k-2}{k-1}.
```

求 $\mathrm{OPT}$，求算法输出的费用，并取 $\varepsilon \downarrow 0$ 时的极限。

## 问题 5：租赁价格变化时的租或买问题

你需要在连续的 $T \ge 1$ 天中每天使用一台机器。期限 $T$ 未知：每天开始时，你知道当天需要使用机器，但不知道之后是否还有一天需要使用。永久购买该机器的费用为 $B \gt 0$。

第 $t$ 天开始时，当天租金 $r_t \gt 0$ 才会公布。如果你尚未购买机器，可以支付 $r_t$ 租用，或支付 $B$ 购买。购买发生在当天使用机器之前，因此不必支付当天租金。此后所有天数的使用均免费。所有价格均为有理数。离线最优解预先知道 $T$ 和所有价格。这里，称一个算法为 $c$-竞争的，是指它对每个有限输入均满足 $\mathrm{ALG} \le c\,\mathrm{OPT}$，且没有加性常数。

考虑以下*阈值算法*。令 $R$ 为至今已支付的租金总额。在购买之前，每个需要使用机器的日子执行：

```math
\begin{cases}
\text{购买}, & R + r_t \ge B,\\
\text{租用并更新 } R \leftarrow R + r_t, & R + r_t \lt B.
\end{cases}
```

**(a)** 证明

```math
\mathrm{OPT} = \min\left\{B, \sum_{t=1}^{T} r_t\right\}.
```

**(b)** 设 $B = 10$，且 $(r_1, r_2, r_3, r_4) = (3, 4, 5, 1)$。求阈值算法每天的决策、总费用和 $\mathrm{OPT}$。另一种规则是先一直租用，直到累计已支付租金至少为 $B$，然后在下一次需要使用机器的日子购买。证明当租金可以变化时，该规则没有有限的竞争比。

**(c)** 证明阈值算法在购买前始终保持 $R \lt B$。证明：如果它从未购买，那么其费用等于 $\mathrm{OPT}$；如果它购买，那么 $\mathrm{OPT} = B$ 且 $\mathrm{ALG} \lt 2B$。据此推出它是 2-竞争的。

**(d)** 固定整数 $M \ge 2$，仅考虑每天 $r_t = B/M$ 的输入。确定阈值算法何时购买，并证明它在此实例族上的精确竞争比为 $2 - 1/M$。据此推出它在完整的变动租金问题上的竞争比恰好为 $2$。

**(e)** 证明对完整问题，不存在竞争比小于 $2$ 的确定性在线算法。

*提示：* 首先证明 (d) 中实例族的下界为 $2 - 1/M$。在无限延续的固定租金序列上模拟该算法。如果它第一次购买的日子是 $\tau$，就在第 $\tau$ 天停止，并分别讨论 $\tau \le M$ 和 $\tau \gt M$。还要处理算法永不购买的情形。最后令 $M$ 增大。

## 问题 6：带容量的在线匹配

离线顶点集 $V$ 预先已知。每个顶点 $v \in V$ 都有一个整数容量 $b_v \ge 1$，以二进制给出。在线顶点按对抗性的顺序逐个到达。在线顶点 $u$ 到达时，其邻居集合 $N(u) \subseteq V$ 才会揭示。算法必须立即将 $u$ 分配给一个仍有剩余容量的邻居，或者永久拒绝 $u$。分配不可撤销，每个在线顶点至多被分配一次。目标是最大化分配数量。

考虑以下贪心算法：每当一个在线顶点到达时，如果有剩余容量的邻居存在，就把它分配给其中任意一个；否则拒绝它。

对于输入序列 $I$，令 $\mathrm{ALG}(I)$ 表示该算法作出的分配数量，令 $\mathrm{OPT}(I)$ 表示预先知道整个序列的离线算法所能达到的最大分配数量。这里，称算法为 $\alpha$-竞争的，是指它对每个有限输入序列 $I$ 均满足

```math
\mathrm{ALG}(I) \ge \alpha\,\mathrm{OPT}(I)
```

且没有加性项。

**(a)** 设 $V = \{a, b\}$，容量为 $b_a = 2$、$b_b = 1$。三个在线顶点按 $u_1, u_2, u_3$ 的顺序到达，其中

```math
N(u_1) = \{a, b\}, \qquad N(u_2) = \{a\}, \qquad N(u_3) = \{a\}.
```

如果贪心算法在两个选择均可用时优先选择 $a$，求它的分配及目标函数值。找出一个最优离线分配。

**(b)** 说明如何为每个离线顶点使用一个计数器来实现贪心算法。解释尽管容量以二进制编码，其运行时间为什么仍关于输入长度为多项式。你的实现不应为顶点 $v$ 创建 $b_v$ 个副本。

**(c)** 固定一个输入序列和一个最优离线分配。令 $A$ 为贪心算法分配的在线顶点集合，令 $O$ 为最优解分配的在线顶点集合。令

```math
S = \{v \in V : \text{贪心算法用尽顶点 } v \text{ 的全部 } b_v \text{ 单位容量}\}.
```

证明 $O \setminus A$ 中的每个顶点都被最优解分配给 $S$ 中的某个顶点。由此推出

```math
|O \setminus A| \le \sum_{v \in S} b_v \le |A|.
```

**(d)** 利用 (c) 证明贪心算法是 $1/2$-竞争的。

**(e)** 证明在此模型中，没有确定性在线算法能获得严格大于 $1/2$ 的竞争比。

*提示：* 使用容量均为 $1$ 的两个离线顶点 $a, b$。第一个在线顶点的邻居集合为 $\{a, b\}$。观察算法对第一个顶点作出的决策后，再选择第二个在线顶点的邻居集合。论证还应覆盖算法拒绝第一个顶点的情形。
